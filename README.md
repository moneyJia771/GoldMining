# 🏆 黄金挖矿游戏 (Gold Mining Game)

一个有趣的HTML5黄金挖矿游戏，使用纯JavaScript开发，具有音效和粒子特效。

## 🎮 游戏介绍

在这个游戏中，你将扮演一名矿工，使用钩爪来挖掘地下的珍贵物品。你需要在60秒内收集足够的金币来达成目标！

### 🎯 游戏目标
- 在限定时间内收集足够的金币
- 默认目标：500金币
- 时间限制：60秒

### 💎 物品类型
- **黄金** 💰 - 价值100金币，重量适中
- **白银** 🥈 - 价值50金币，较轻
- **钻石** 💎 - 价值200金币，最轻最珍贵
- **石头** 🪨 - 价值10金币，最重

## 🕹️ 操作方法

1. **开始游戏**：点击"开始游戏"按钮
2. **发射钩爪**：
   - 点击屏幕任意位置
   - 或按下空格键
3. **重新开始**：点击"重新开始"按钮

## 🎵 特色功能

- **动态音效**：不同物品有不同的音效
- **粒子特效**：抓取物品时的爆炸效果
- **响应式设计**：支持移动设备
- **流畅动画**：钩爪摆动和伸缩动画

## 🚀 运行游戏

1. 下载或克隆此项目
2. 在浏览器中打开 `index.html` 文件
3. 开始享受挖矿的乐趣！

## 📱 兼容性

- 支持所有现代浏览器
- 移动设备友好
- 需要支持Web Audio API的浏览器以获得音效体验

## 🛠️ 技术栈

- **HTML5** - 游戏结构
- **CSS3** - 样式和动画
- **JavaScript ES6+** - 游戏逻辑
- **Web Audio API** - 音效系统
- **Canvas API** - 粒子特效

## 🎯 游戏策略

- 钻石价值最高但数量稀少，优先抓取
- 注意物品的重量，重物会让钩爪收回更慢
- 合理分配时间，不要在低价值物品上浪费太多时间
- 观察钩爪摆动的节奏，把握最佳时机

## 🔧 自定义设置

你可以在 `script.js` 中修改以下参数：

```javascript
// 游戏设置
this.timeLeft = 60;      // 游戏时间（秒）
this.target = 500;       // 目标分数
```
