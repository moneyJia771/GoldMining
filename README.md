## 项目概述

《黄金矿工》H5版是一款经典休闲游戏的网页重制版，玩家通过控制钩子抓取矿洞中的黄金和宝物，在规定时间内达到目标金额即可过关。游戏适配移动端和PC端，操作简单，体验流畅，具备一定的挑战性和趣味性。

## 游戏特点

- **经典玩法**：复刻经典《黄金矿工》的核心玩法，保留原汁原味的游戏体验
- **简单操作**：点击/触摸屏幕或按空格键即可发射钩子
- **多种物品**：金块（大中小）、钻石、石头等不同价值和重量的物品
- **关卡系统**：随着关卡提升，难度逐渐增加，目标金额提高，时间减少
- **响应式设计**：同时支持移动端和PC端，自适应不同屏幕尺寸

## 技术栈

- **HTML5**：构建游戏界面结构
- **CSS3**：实现游戏界面样式和动画效果
- **JavaScript**：实现游戏核心逻辑和交互功能
- **Canvas API**：绘制游戏场景和动画

## 游戏功能

### 核心玩法机制

- **钩爪发射**：
  - 钩爪在发射前会像钟摆一样左右匀速摆动
  - 点击/触摸屏幕或按空格键发射钩爪
  - 钩爪沿当前摆动切线的直线方向射出

- **抓取判定**：
  - 钩爪头部与场景中的物品发生碰撞时，即视为抓取成功
  - 钩爪只能抓取碰到的第一个物品，抓到物品后立即收回

- **物品回收与售卖**：
  - 钩爪抓到物品后，会沿直线轨迹收回
  - 不同物品有不同的重量，影响回收速度
  - 物品成功回收后，其对应的金币价值会立即添加到玩家的总资金中

- **时间与目标**：
  - 每一关都有一个明确的目标金额
  - 在倒计时结束前，总资金 ≥ 目标金额，则闯关成功
  - 倒计时结束时，总资金 < 目标金额，则闯关失败

### 物品系统

- **金块**：基础物品，分为大、中、小三种尺寸，尺寸越大，价值越高，重量越大，回收速度越慢
- **钻石**：高价值物品，体积小，重量轻，回收快
- **石头**：低价值物品，重量大，会浪费玩家的时间和机会

### 关卡系统

- **关卡设计**：关卡难度递进，表现为：
  1. 目标金额提高
  2. 时间减少
  3. 物品布局更复杂
  4. 出现更多干扰物品
- **关卡选择**：提供关卡选择界面，可以选择已解锁的关卡进行挑战

### 游戏界面

- **开始界面**：游戏Logo，开始游戏、关卡选择、设置按钮
- **游戏界面**：显示当前关卡、目标金额、当前金额、剩余时间
- **结束界面**：
  - 成功界面：显示"闯关成功！"，获得的星星评价，下一关、重玩、返回按钮
  - 失败界面：显示"再接再厉"，重新开始、使用道具、返回按钮
- **暂停界面**：继续游戏、重新开始、退出关卡按钮
- **关卡选择界面**：显示所有关卡，已解锁的可以点击进入

## 如何运行

1. 克隆或下载本项目到本地
2. 使用HTTP服务器运行项目（如Python的http.server模块）：
   ```
   python3 -m http.server 8000
   ```
3. 在浏览器中访问 `http://localhost:8000`

## 游戏操作

- **PC端**：点击鼠标或按空格键发射钩子
- **移动端**：触摸屏幕任意位置发射钩子
